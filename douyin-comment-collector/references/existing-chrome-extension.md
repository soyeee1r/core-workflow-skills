# 使用 Codex 已连接的当前 Chrome

这是首选采集路径。它复用用户已经登录的 Chrome，不依赖固定 CDP 端口，不导出 Cookie，也不启动独立浏览器。

## 必须遵守

- 完整读取并执行 `chrome:control-chrome` Skill；只使用它规定的 Node 浏览器运行时控制 Chrome。
- 会话名使用 `🏢 抖音评论扫楼`。只创建或控制本任务所需的临时标签页，不读取浏览历史、其他标签页内容、Cookie、Local Storage、密码或会话文件。
- 不申请下载、摄像头、麦克风、位置或媒体权限；不点赞、回复、关注、举报或发布。
- 登录、验证码或安全验证出现时立即停止，返回唯一的人工下一步，不代替用户处理。

## 页面顺序

1. 从输入链接解析 `video_id` 和可见标题。
2. 若当前登录账号能在抖音创作者中心找到该作品，优先进入该作品的评论管理页。按最热/推荐或页面提供的互动排序读取顶层评论和可展开回复。
3. 创作者中心找不到该作品时，在同一 Chrome 的临时标签页打开输入链接，进入作品评论区并使用页面当前可见排序。
4. 每轮只读取当前任务页的可见 DOM；展开可见回复并滚动评论容器。把每轮新出现的评论按评论 ID 去重；没有 ID 时用作者、正文、时间和父评论指纹去重。
5. 达到 100 条、页面明确到底或连续三轮无新增即停止。关闭或释放本任务临时页，不关闭用户原有页面。

## 原始数据

把累计结果写成 `raw-comments.json`，结构与 `references/schema.md` 一致，至少包含正文、作者显示名、点赞数、回复数、显示时间/地区、父子关系、置顶/作者标记和可见评论 ID。不可见字段写 `null`，不得猜成 `0`。

记录 `backend: "existing_chrome_extension"`、最终 URL、作品标题、排序模式、实际条数和停止原因。随后必须继续运行规范化、排序、文档与卡片交付流程。

## 失败映射

- Chrome 连接或扩展不可用：回退 `existing-chrome-cdp.md`。
- 创作者中心未登录但公共作品页可见：继续公共作品页，不要求多余登录。
- 两个页面都要求登录：`needs_login`。
- 验证码、滑块或安全验证：`needs_human`。
- 页面连续三轮无评论但没有明确空状态：`collection_failed`，保留作品链接和精确阶段。

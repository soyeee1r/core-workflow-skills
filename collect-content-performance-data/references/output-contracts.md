# 输出契约

## 文档对比表

标题使用 `<正式项目名>-数据回收`；没有正式项目名时使用 `<视频标题>-数据回收`。按 `project_id` 复用“我的文档库/数据回收”中的同一份飞书文档，不创建独立电子表格或第二份文档。正文只保留一张抖音四窗口对比表：

```text
指标 | 2h | 6h | 24h | 48h | 口径/备注
```

每个窗口另存采集时间、原始 JSON 证据和 `metric_snapshot_id`。主文档展示匿名公开接口实际可用的点赞、评论、分享、收藏等指标；播放量在“播放量补充观测”独立表格中展示，必须带采集时间、发布后时长和精度。无当时证据的 2h/6h 不倒填。除播放量外的后台专属指标仍标明不可用。

播放量补充观测表固定为：

```text
采集时间 | 发布后 | 后台显示 | 图表换算 | 精度/备注
```

每个窗口另追加一段“阶段概述”，说明相对上一有效窗口的净增、增幅、增长是否放缓/加速及可由数据直接支持的运营或内容观察。2h 是基线，不强算环比；所有概述只追加，不覆盖。

证据附录保留以下窗口详情：

```text
发布后 <2h|6h|24h|48h> 数据｜抖音 · 匿名公开接口 · <视频标题或内容 ID>

发布时间｜2026-08-07 10:00（Asia/Shanghai）
采集时间｜2026-08-08 10:12（发布后 24.20h，on_time）
内容链接｜<canonical_url>

核心指标
- 点赞：456
- 评论：34
- 分享：21
- 收藏：18

其他平台原始指标
- <原字段名>：<显示值>（<单位/口径>）

数据边界
- 播放量、曝光、完播率、平均观看时长、跳出率、流量来源和观众画像：公开接口不可用

数据证据｜<public-metrics.json 路径或附件>
metric_snapshot_id｜ms_xxxxxxxxxxxxxxxx
```

只展示实际可用指标。不可用字段不必堆满正文，但需在结构化快照保留 `availability` 与原因。不要在这个区块写“表现好/差”或归因结论。

## 互动网页

- 每个 `video_id` 对应一个独立飞书妙搭 HTML 应用，页面 URL 稳定；2h、6h、24h、48h 只更新该页面，不覆盖其他作品。
- 页面必须由 Skill 的 `build_interactive_report.mjs` 生成，不能手写一个只含数字卡和文字环比的静态页面。
- 页面至少包含作品标题、四窗口公开指标卡、夸克播放量补采点、可交互增长折线图、累计/净增切换、播放/点赞/评论/分享/收藏指标切换、窗口筛选、评论/弹幕页签、高频话题频次条、弹幕时段密度、代表性好评/差评/明确问题、当前窗口状态、采集时间和两路数据边界。
- 评论与弹幕变化只展示实际保存的窗口；首个文本快照标记为基线，后续显示较上一真实快照新增量和话题频次净变化。没有历史证据时明确缺失，不补造。
- 页面必须是自包含 `index.html`，设为公开、`require_login=false`，并通过未登录 HTTP 回读；不能使用 `chatgpt.site`、本地地址或临时预览地址。
- 匿名回读除标题、窗口和数据边界外，还必须确认 `data-chart="metric-trend"`、`id="metric-controls"`、`data-mode="delta"`、`id="audience-panel"`、`data-channel="comments"`、`data-channel="danmaku"` 存在；缺任一项不能把 `web_verified_interactive` 标为 true。

## 阶段回执

```text
<2h|6h|24h|48h> 公开数据回收已完成
互动网页：<web_url>
飞书文档：<doc_url#anchor>
采集于发布后 <age>h，共写入 <count> 个公开指标；原始证据已保存。
```

## 48h 完整项目复盘与最终回执

48h 后在同一文档形成公开数据复盘，至少包含：四窗口指标总表、相邻窗口净增/增幅、互动增长节点、数据质量与异常、可复用经验、问题及下一次发布行动项。后台专属数据保持不可用，不做无证据归因。

48h 群通知同时承担阶段回执和最终回执，只发一次，不额外发送第五条消息。

```text
48h 数据回收及项目复盘已完成，2h/6h/24h/48h 四窗口对比如下：
- <指标>：<2h> → <6h> → <24h> → <48h>（相邻增量/增幅）
完整数据与证据：<doc_url>
```

## 阻塞回执

第一句说明卡点，再给唯一下一步：

- `未到窗口`：说明窗口和 `due_at`，保持 scheduled；
- `公开接口失败`：说明失败窗口、内容 ID 和下一次自动重试时间；不得切换浏览器；
- `定位不唯一`：列出缺少的平台、账号、内容 ID/链接或项目映射；
- `文档创建失败/无权限`：说明已尝试在个人文档库创建的标题，并请求权限；
- `write_conflict`：给出现有与新快照 ID/关键差异，不覆盖。

不要声称“已写入”直到回读一致。

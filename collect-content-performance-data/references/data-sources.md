# 数据源与定位：公开主链路 + 夸克播放量

## 公开主链路

抖音发布后数据回收只允许调用本 Skill 的匿名公开采集器：

`node scripts/collect_douyin_public_metrics.mjs --url '<抖音链接>' --output '<证据目录>/public-metrics.json'`

采集器为当前进程建立一次性匿名访客会话，读取抖音公开分享页中的作品详情与统计字段。会话不关联用户账号，不保存 Cookie，不调用 Chrome、Playwright、浏览器控制、账号后台或远程调试。

## 输入映射

真实运行前必须具备：

`project_id → publication_id → douyin video_id / canonical_url → target_doc_url / web_app_id`

- 用作品 ID 或唯一链接定位，不得只凭相似标题。
- 采集结果中的 `video_id` 必须和 Publication 一致。
- 公开 `create_time` 与暂定发布时间不一致时，保留两者来源，以公开时间计算快照龄并修正尚未执行的窗口。

## 可用与不可用

- 可用：点赞、评论、分享、收藏，以及公开响应中其他定义明确的非占位计数。
- 不可用：曝光、播放量占位值、独立观看、平均观看时长、完播率、跳出率、回看率、跳过率、流量来源、观众画像、主页访问和新增关注。
- 接口没有字段时写 `unavailable`；请求或解析失败时写 `collection_failed`；两者都不能写 0。

## 飞书文档与妙搭

用 `lark-doc` 在用户“我的文档库/数据回收”创建或复用同一项目文档。用 `lark-apps` 为每个 `video_id` 创建或更新独立 HTML 应用，设为公开且 `require_login=false`，发布后以匿名 HTTP 请求回读。文档和网页只有同时回读一致，窗口才完成。

评论与弹幕只使用 `douyin-comment-collector/scripts/collect_sweep.mjs` 的匿名公开链路。每个窗口重新采集当前公开可见范围，保存原始结果后计算与上一真实快照的新增量和话题变化；不得以当前结果伪装历史快照。

公开分享页 `play_count=0` 不能作为真实播放量。禁止用点赞、评论或第三方估算替代。

## 夸克补充链路（仅播放量）

1. 使用电脑控制读取本机已存在的夸克窗口，打开或复用抖音创作者中心作品详情页。
2. 用 URL 中的 `video_id` 和页面作品标题双重核对，只读“播放量”一项。
3. 页面显示缩写数值时保留原始展示和精度说明。例如 `38.86万` 记为“约 388,600，页面按万保留两位小数”。
4. 写入作品证据根目录的 `playback-observations.json`，然后由网页生成器合并；已完成的 2h/6h 历史窗口没有当时观测时，不得倒填。

这条链路不使用 Chrome，不读取或导出 Cookie/Local Storage/历史记录，不开远程调试，不要求用户截图，不点击导出，不申请下载、媒体、摄像头或麦克风权限。页面可见的其他后台指标不采集。

## 定时

事件层收到可信发布消息后创建 `published_at + 2h/+6h/+24h/+48h` 四个精确单次任务。进程重启只恢复尚未执行的窗口；已经过期的窗口立即补跑并标记实际快照龄。禁止周期扫描。
